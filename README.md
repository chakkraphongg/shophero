## 🛠️ 2. ระบบหลังบ้าน (Admin Panel) แก้ไขในหน้าเว็บได้ทันที

คุณสามารถเข้าใช้งานระบบหลังบ้านได้โดย:
1. เปิดไฟล์ [`admin.html`](file:///c:/Users/chakk/Desktop/sell/admin.html) บนบราวเซอร์ หรือคลิกปุ่ม **"⚙️ หลังบ้าน (Admin)"** บนแถบเมนู
2. คลิกปุ่มลอย **"⚙️ จัดการร้านค้า (Admin)"** ที่มุมล่างซ้ายของหน้าเว็บ

### ฟังก์ชันที่มีในระบบหลังบ้าน:
- **แก้ไขข้อมูลร้านค้า:** เปลี่ยนชื่อร้าน ("ขายทุกอย่าง"), คำโปรย, ลิงก์ LINE, ลิงก์ Facebook Messenger, เบอร์โทร
- **ปรับเปลี่ยนราคาแบบ Real-time:**
  - คลิกปุ่มสลับ **"🔥 15.- (SALE)"** หรือ **"ปกติ 20.-"** ได้ทันทีในแต่ละตัว
  - ปุ่มด่วน: **"ตั้งราคา 20.- ทุกตัว"** หรือ **"จัดโปร 15.- ตัวยอดนิยม"**
- **สลับสถานะสินค้า:** คลิกที่ป้ายสถานะเพื่อเปลี่ยนระหว่าง `🟢 พร้อมส่ง` หรือ `🔴 สินค้าหมด`
- **เพิ่มฮีโร่ใหม่:** กดปุ่ม **"+ เพิ่มฮีโร่ใหม่"** เพื่อกรอกชื่อ, สเตตัส, ราคา และรูปภาพ
- **บันทึกข้อมูลอัตโนมัติ:** บันทึกสดลงใน LocalStorage ของบราวเซอร์ เมื่อเปิดหน้าเว็บหลักจะเห็นผลลัพธ์ทันที!

## 🚀 3. วิธีนำการแก้ไขขึ้น GitHub Pages (Export for Deployment)

เมื่อคุณแก้ไขข้อมูลในหน้า `admin.html` เรียบร้อยแล้ว:
1. ไปที่แท็บ **"🚀 ส่งออกไฟล์ & Deploy GitHub Pages"** ในหน้า Admin
2. คลิกปุ่ม **"📥 1. ดาวน์โหลดไฟล์ products.js ใหม่"**
3. นำไฟล์ `products.js` ที่ดาวน์โหลดมา ไปวางแทนที่ไฟล์เดิมในโฟลเดอร์ `c:\Users\chakk\Desktop\sell\js\products.js`
4. อัปโหลดขึ้น GitHub หรือรันคำสั่ง:
   ```bash
   git add .
   git commit -m "Update heroes and store settings from admin"
   git push origin main
   ```
5. เว็บไซต์บน GitHub Pages จะอัปเดตเป็นข้อมูลใหม่ล่าสุดทันที!

## 🎮 4. ลูกเล่น 3D Hologram Stage (หมุนตัวละคร 3D)

- **หมุนตัวละคร 360°:** คลิกเมาส์ค้างแล้วลาก (หรือใช้นิ้วปัดบนจอมือถือ) ตัวละครจะหมุนตามแกน 3D Perspective อย่างสมจริง
- **โหมดหมุนอัตโนมัติ:** กดปุ่ม **"🔄 หมุนอัตโนมัติ"** เพื่อให้โมเดลหมุนวน 360° ตลอดเวลา
- **ส่อง 3D จากหน้ารวมสินค้า:** บนการ์ดฮีโร่ทุกใบจะมีปุ่ม **"🔄 หมุน 3D"** เมื่อกดแล้วจะเปิดหน้าต่าง Quick Inspect 3D ขึ้นมาพร้อมสเตตัสในเกมทันที
- **3D Card Hover Tilt:** เลื่อนเมาส์ผ่านการ์ดสินค้าในหน้าแรกและหน้ารวม จะมีเอฟเฟกต์การ์ดเอียง 3D ตามตำแหน่งเมาส์

## ⚡ 5. ข้อมูลฮีโร่และสเตตัสในเกม (WarZ Hero Armory)

ข้อมูลฮีโร่ถูกดึงมาจาก Game Database:
- **⚡ SpeedRun (%):** ความเร็วในการวิ่ง
- **🛡️ DeffHero (%):** พลังป้องกันของตัวละคร
- **💖 RegenHP (HP/s):** อัตราการฟื้นฟูพลังชีวิต
- **👑 TIER:** แบ่งระดับตามความแรร์ (SSS Tier, SS Tier, S Tier)
